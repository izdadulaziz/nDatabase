# nDatabase

Simple database library written in Java.

## Features

- Create database
- Insert record
- Read record
- Update record
- Delete database
- Search record
- Find record
- Remove record

## Requirements

- Java 17
- Maven

## Installation

Clone repository:

```bash
git clone https://github.com/izdadulaziz/nDatabase.git
cd nDatabase
mvn package 
```
